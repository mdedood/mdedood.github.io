Introduction

This online course is designed as part of the Research Skills and Scientifc Integrity course at Leiden University and is intended for third year physics students, , but may also be useful for other students with a similar background. This short course introduces the statistical and data-analysis tools that are commonly used in experimental physics and equips you with tools that you need during your research project. The focus is not only on performing calculations, but on interpreting data, assessing uncertainty, and drawing scientifically sound conclusions.


You will learn how to analyse data using Python, evaluate hypotheses using statistical tests, fit models to data, and critically assess the results — including their limitations. Throughout the course, these methods are applied to realistic physics examples and real-world data, reflecting the kinds of problems encountered in laboratory courses, bachelor projects, and research. This course assumes that you have working knowlegde of Python, can work with Jupyter notebooks and that you have some prior exposure to experimental physics including data collection, data visualization and have done some least square fitting of data by using a standard Python library, e.g. SciPy. No advanced background in statistics is assumed; the necessary concepts are introduced as they are needed.

How this course works

The course consists of short explanatory texts combined with interactive Jupyter notebooks. The notebooks contain exercises in which you analyse data, perform fits, and explore statistical behaviour numerically. Rather than focusing on abstract theory alone, the emphasis is on learning by doing: applying methods to realistic examples, interpreting results, and reflecting on their meaning in a scientific context.


The course is divided into four modules. The modules build on each other: you will start by developing good scientific practice and core statistical concepts, and then move on to more advanced fitting techniques and applications to real data. Each module contains a part A and part B. Each part is designed to take 1-1.5 hour to complete and contains a combination of quizzes using Google forms, some instruction videos and a set of Jupyter notebooks with detailed instructions, lecture notes etc. In principle these modules can be completed individually and independently, but discussion in small groups of 2-5 students is encouraged and highly recommended.


For physics students at Leiden university live sessions are planned for each part. These sessions will consist of 30 min. of interactive lecture/discussion on part A of each module. Short instructions and a question and answer session is available for the B part of the module afterwards. Students are expected to come prepared by completing the A part of each module. The B part of each module contains at least one exercise that needs to be handed in.

Module content and learning goals

Module 1A // Data analysis, mistakes and misconduct

This module introduces principles of scientific integrity, data presentation, and critical interpretation. You will learn how figures can mislead, how to improve data visualisation, and how errors or misconduct have affected real scientific results through several case studies.

After completing this module the student:
- is able to name and explain ethical guidelines for conducting scientific research;
- is able to distinguish between scientific mistakes and scientific misconduct;
- can give a few examples of scientific mistakes and misconduct and discuss these with others


Module 1B // Errors, hypothesis testing and goodness of fit

In this module you develop the foundations of statistical data analysis. Topics include measurement errors, weighted averages, hypothesis testing using χ², and assessing the quality of fits. These tools form the basis for much of experimental data analysis in physics.
More specifically, the student can:
- calculate the chi-squared value and use this to test a hypothesis;
- asses the quality of a fit using the χ² distribution;
- dicuss the differences between various methods to fit a straight line


Module 2A // Non-linear-least-squares fitting

This module extends fitting techniques to non-linear models and introduces propagation of errors. You will apply these methods to realistic physics problems such as exponential decay, the Cavendish experiment, and spectral peak fitting, and learn about practical challenges such as local minima and parameter correlations.

This module contains three examples that teach the student to:
- apply non-linear-least-squares fitting in different settings;
- use the method of error propagation to calculate the error bar on a data point and discuss the consequences for non-linear-least-squares fitting;
- understand the importance of initial parameters and find the overall best fit parameters;


Module 2B // Global warming in the Netherlands?

In the final module you apply the techniques learned earlier to real observational data. Using climate data as an example, you will analyse trends, evaluate statistical significance, and reflect on the interpretation and limitations of statistical conclusions drawn from complex, real-world data sets using Pandas.
After completion the student is able to:
- use Pandas (in Python) on large online datasets.
- have an informed opinion whether or not the rise in temperature in the Netherlands over the past century is statistically significant.
- apply all the skills from all above modules to complete this final exercise.
